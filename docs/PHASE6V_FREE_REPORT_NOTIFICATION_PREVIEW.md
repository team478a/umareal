# Phase 6V 無料情報配信の配信前確認

## 完成条件

- 無料パドック速報の即時公開・予約公開と、レース後検証の即時公開前に、次版、対象会員数、予定配送数、LINE・メール別件数、本文、JSTの配信時刻を確認できる。
- プレビュー取得だけでは無料速報版、通知event、配送、監査履歴を作らない。
- 保存済み下書きのrevisionと、公開時に必要な発走時刻・レース・出走馬・確定結果の条件を検証する。
- API応答と通知本文に評価馬、評価理由、検証本文、会員識別情報、資格情報を含めない。
- スマートフォンで「下書き保存→配信内容確認→公開または予約」の順に操作できる。

## 実装

- `GET /api/v1/admin/notifications/previews/free-report`
  - `raceId`、`kind`、保存済みの`revision`が必須。
  - 発走前速報の予約確認だけ`scheduledAt`を指定できる。
  - ADMIN+AAL2またはOPERATORに限定する。
  - 実配送と同じ対象条件・共通通知文面を使用する。
- `/admin/free-reports`
  - 発走前速報とレース後検証を配信前確認から公開する。
  - 編集または再読込で古いプレビューを破棄する。
- `/admin/publication-schedules`
  - 対象レース告知と無料パドック速報の両方を配信前確認から予約する。
  - 予約後に下書きrevisionが変わった場合は従来どおり実行を拒否する。

## 運用上の境界

表示人数はプレビュー取得時点のスナップショットであり、宛先の固定や送信保証ではない。公開・予約確定時に条件を再検証し、ワーカーも配送展開時と送信直前に最新の会員状態、通知設定、閲覧権限、チャネル緊急停止を確認する。レース後検証は確定結果を確認してから即時公開する。外部LINE・Resendへのライブ疎通と本番配信は別工程で行う。
