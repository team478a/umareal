# Phase 5G 会員転換ファネル

無料登録から有料化までのどこで会員が止まっているかを、個人別の閲覧履歴を管理画面へ出さずに確認できるようにした。

## 実装範囲

- 無料登録、本人確認、LINE受信準備、料金閲覧、申込確認、有料化の6段階を集計する。
- 管理ダッシュボードに直近30日登録者の人数・登録者比率と、全期間の人数を表示する。
- 料金ページ閲覧と申込内容確認は、ログイン会員ごとに初回到達だけを保存する。
- 行動イベント種別はサーバーの許可リストで制限し、再送や同時実行でも一意制約により重複させない。
- 有料化は成功した支払試行、現在の利用状態は有限期間の閲覧権限として別々に集計する。
- 管理集計APIはサーバー所有のロールとAAL2で保護する。

## 集計の読み方

直近30日は「過去30日間に登録した会員」が、その後どの段階へ到達したかを示す。料金閲覧と申込確認はPhase 5Gの計測開始後だけ取得する。計測開始前の操作は推測で補完しないため、初期期間は有料化人数が前段階より多くなる場合がある。

## 境界

外部解析サービス、広告識別子、ページ全体の閲覧ログ、個人別行動一覧、A/Bテスト、外部決済、CMS、本番デプロイは含めない。正式なプライバシーポリシーと保存期間は本番前に決定する。
