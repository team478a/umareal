# AIレースガイド Data Source Matrix

作成日: 2026-10-05
基準main: `92bc7024ebb941744081b461bdb9e6600cb4e8ec`

## 判定の読み方

- `YES`: 公開仕様または現行コードから技術的な取得可能性を確認できた
- `CURRENT`: 現行RA/SE bridgeが正規化CSVへ出力している
- `NO`: 現行bridgeでは取得・保存していない
- `UNKNOWN`: 現行SDK・実契約・提供タイミングの確認が必要
- `LEGAL_REVIEW_REQUIRED`: 書面による利用許諾が未確認
- 優先度 `A`: V1最小構成、`B`: V1任意、`C`: 将来候補

`YES`は利用許諾を意味しない。JRA-VAN公式案内では、Data Lab通常契約のデータをエンドユーザーへ提供する有料サービスは二次利用に当たり、通常契約だけでは実施できず、法人向けJRADB契約が必要とされている。そのためJRA-VAN/JRADB候補のStorage、Derived、Display、External AIは、契約書面を確認するまで一律`LEGAL_REVIEW_REQUIRED`とする。

## 現行RA/SE bridge監査

| 観点 | 現状 |
| --- | --- |
| dataspec | `JVOpen("RACE", ..., option=2)`のみ |
| record | RA 1272 bytes、SE 555 bytes。その他recordは破棄 |
| RA mapping | 日付、競馬場、番号、名称、クラス、距離、芝/ダート、回り、発走時刻、馬場、天候 |
| SE entry mapping | 血統登録番号由来UUID、馬番、枠、馬名、性齢、斤量、騎手、調教師、単勝オッズ、人気、異常区分 |
| SE result mapping | 確定着順、最終人気、最終単勝オッズ、異常区分、レース中止 |
| source key | Raceは日付・場コード・レース番号、Entry/Resultはそれに馬番を追加。Horse UUIDは血統登録番号の決定的UUID |
| revision | bundle間のartifact hashと結果対象集合を比較し、変更なし・結果追加・結果訂正候補・レース変更等を分類。自動反映しない |
| update timing | 現行live commandは指定日の今週RACEを明示実行する方式。定期運用時刻は未決定 |
| retention | raw RA/SE、血統登録番号、利用キーをDB/manifestへ保存しない。bundle保持期間は契約確認が必要 |
| provenance | manifestにRA/SE件数・SHA-256・format version・artifact hashを保持。ただしDBのRace/Entry各行からsource record、作成日、import batchへ直接たどる永続linkは未実装 |
| correction gap | `RaceResultVersion.sourceRevision`はあるが、RA/SEのデータ作成年月日・データ区分を永続provenanceとして保持していない |

## Data source候補比較

| 候補 | 技術適合 | 商用利用 | 注意 |
| --- | --- | --- | --- |
| JRA-VAN Data Lab通常契約 | 高い | 不可 | 公式案内上、エンドユーザーへの商用提供は通常契約では不可 |
| JRADB法人契約 | 高い候補 | 契約確認必須 | 料金、項目、保存、派生、再配信、外部AI条件は非公開。法人として問い合わせる |
| 別の商用data provider | UNKNOWN | 契約確認必須 | 同じfield単位checklistで比較。名称だけで権利を推定しない |
| 自社入力・自社観測 | 中 | sourceごとに確認 | 人が入力しただけで第三者データの権利問題が消えるわけではない |
| 自社蓄積したUMAREAL公開・結果履歴 | 高い | 社内規程確認 | 三国谷データは事前Factへ混ぜない。競馬の公式事実の権利は別途確認 |
| 公開Web scraping | 対象外 | 不可前提 | 利用規約・robots・著作権等を未確認のまま採用しない |
