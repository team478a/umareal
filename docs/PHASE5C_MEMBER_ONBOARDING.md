# Phase 5C 会員利用準備と有料化導線

無料会員登録後に対象レース告知と最終予想を受け取り、必要に応じて有料プランの確認へ進めるスマートフォン向け導線を実装した。

## 実装範囲

- マイページに、無料登録、LINE通知、予備ログイン、有料閲覧の4段階チェックリストを表示する。
- 会員APIがLINE未連携、LINE側ブロック、通知設定オフ、受信準備済みをサーバー所有データから判定する。
- 通知設定オフはチェックリストから対象レース告知・最終予想通知だけを有効にできる。
- LINE側ブロックは公式アカウントの再追加を案内し、連携済みと受信可能を区別する。
- 未公開レース詳細からLINE通知設定へ、有料予想のロック画面から料金プランへ移動できる。
- 開発用料金申込に最終確認を追加し、プラン、料金、利用期間、1日利用日を確定前に表示する。

## 境界

外部決済、カード情報、実請求、正式な販売条件、CMS、LINE・メールのライブ疎通、本番デプロイは含めない。料金画面の申込はローカル試験用で、正式条件と同意画面は外部決済導入時に置き換える。
