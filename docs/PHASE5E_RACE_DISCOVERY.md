# Phase 5E レース検索導線

会員が告知やLINEを見失っても、開催日と公開状態からレースを探し直せるスマートフォン向け一覧を実装した。

## 実装範囲

- 全員が利用できる`/races`画面とナビゲーションを追加する。
- 開催日の直接選択、前日・翌日・今日への移動に対応する。
- 競馬場、対象レース告知済み、最終予想公開済み、最終予想未公開で絞り込む。
- 未公開、告知済み、無料予想公開、有料予想公開、閲覧可能、中止、訂正版を区別する。
- 一覧APIをページネーションし、選択開催日の競馬場候補を返す。
- 予想本文、印、買い目、総評、信頼度を一覧レスポンスから除外する。

## 境界

有料本文の最終認可はレース詳細APIが行う。一覧の鍵表示は案内用であり、API認可の代わりにしない。信頼度絞り込み、CMS、お気に入り、外部データ検索、本番接続は含めない。
