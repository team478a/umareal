# Phase 5H 開催日運用ボード

開催日に「どのレースで何が止まっているか」を管理トップから判断できるよう、レース準備から結果確定までの状態を一画面にまとめた。

## 実装範囲

- JST日付を前日、翌日、日付入力、今日への復帰で切り替える。
- 担当専門家、告知版、パドック完了頭数、最終予想公開版、通知の送信・待ち・失敗件数、結果確定版を表示する。
- 担当未設定、出走馬未登録、対象レース未告知、パドック未着手・未完了、最終予想未公開・期限超過、通知失敗、結果未確定を警告する。
- 発走30分以内と発走時刻経過を目立たせる。
- レース管理、評価・公開、通知運用、結果管理へスマートフォンでも押しやすい導線を表示する。
- 管理APIはADMIN+AAL2またはOPERATORに限定し、進捗はDBの正本データから計算する。

## 権限

ADMINは全レースを評価・公開画面へ指定付きで開ける。OPERATORは運用ボードを閲覧し、既存権限の範囲でレース、通知、結果を操作する。運用ボードによって専門家の担当制御やAAL2要件を緩和しない。

## 境界

画面は現在値を取得時点で表示し、自動更新や外部監視通知は行わない。実LINE疎通、外部決済、CMS、開催日リハーサル、本番デプロイは含めない。
