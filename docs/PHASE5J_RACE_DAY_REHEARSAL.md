# Phase 5J 開催日リハーサル

開催日の作業順と停止要因を管理ダッシュボードで確認できるようにした。

## 実装範囲

- レース準備、対象レース告知、パドック評価、最終予想公開、通知確認、結果確定を6段階で表示する。
- 各段階を完了、次に確認、待機、要対応、発走後に分類する。
- レースごとの進捗数、次の作業、発走準備完了、阻害要因を表示する。
- CSV取込、予想公開、LINE通知、LINE資格情報を事前確認する。
- 30秒の自動更新、手動更新、情報鮮度警告と同じAPI応答で状態を更新する。
- PCとスマートフォンの両方で確認できる。

## 判定方法

完了状態はDBに保存された担当者、出走馬、告知版、入力済み評価、公開予想版、通知イベント・配送、結果版からサーバーが計算する。公開停止、締切超過、通知停止、LINE設定不足、配送失敗は要対応にする。発走前の結果確定は未完了ではなく「発走後」とする。

## 境界

この機能は既存状態を確認するもので、チェック操作による公開、通知送信、結果確定、履歴更新は行わない。実LINE送信、人手による3分計測、障害連絡訓練、外部監視、本番デプロイは含めない。
