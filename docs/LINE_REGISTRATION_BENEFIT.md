# LINE無料登録特典動画

## 目的

LINEから無料会員登録を完了した一般会員へ、登録特典動画をアプリ内で案内する。動画ファイルの保管・配信機能は持たず、管理対象のHTTPS動画配信先を利用する。

## 対象者

- `role=MEMBER`かつ、サーバーDBの`registrationMethod=LINE`である有効な会員。
- メール登録後にLINEアカウントを連携した会員は対象外。
- 画面表示だけでなく、概要取得と視聴開始APIの両方で対象者を再判定する。
- 対象外の会員には動画設定の有無や動画URLを返さない。

## 会員導線

1. LINE OAuth後に表示名、20歳以上、利用規約、プライバシーポリシーを確認して登録を完了する。
2. `/account?line=registered`へ移動し、登録完了と特典の受取案内を表示する。
3. `/benefit`でタイトルと説明を確認する。
4. 「動画を見る」を押すと、サーバーが対象者と現在の設定を再確認し、初回視聴時刻を記録してHTTPS動画配信先を返す。
5. ホーム、マイページ、会員メニューから後日再視聴できる。

動画を自動再生・自動転送しない。LINE Messaging APIで動画URLを直接送信せず、将来通知を追加する場合もログイン後の`/benefit`への案内を使用する。

## 管理

`/admin/free-reports`でADMIN+AAL2またはOPERATORが固定1枠のタイトル、説明、HTTPS動画URL、変更理由を設定する。同じ画面で現在の対象会員数と視聴開始済み会員数を確認できる。動画URLは監査ログへ保存しない。

## API

- `GET /me/free-benefit`: 対象会員にはタイトル、説明、更新日時、初回視聴日時を返す。動画URLは返さない。対象外または未設定の場合は`configured=false`。
- `POST /me/free-benefit/view`: 対象者と設定を再確認し、動画URLと初回視聴日時を返す。再送しても初回視聴日時は変わらない。
- `GET/PATCH /admin/free-reports/benefit`: 管理用設定と対象・視聴開始済みの集計を返す。

## データと制約

- 特典設定は既存の`free_member_benefits`固定1行を利用する。
- 初回視聴は既存の`member_journey_events`へ`REGISTRATION_BENEFIT_VIEWED`として保存する。`(userId,eventType)`一意制約により再操作でも1件だけを保持する。
- 新しいDBテーブルや閲覧権限は追加しない。既存の許可イベント種別CHECK制約へ`REGISTRATION_BENEFIT_VIEWED`を追加する非破壊migrationだけを適用する。
- 外部配信先のURLを受け取った対象会員による共有までは防げない。強い配信制限が必要な場合は、動画配信事業者の署名付きURLやドメイン制限を別フェーズで検討する。

## 確認項目

- 未認証は概要取得・視聴開始とも拒否される。
- メール登録会員とスタッフは動画情報を取得できない。
- LINE登録会員だけが概要を取得し、視聴開始時だけ動画URLを取得できる。
- 視聴開始APIの再送でイベントや日時が増えない。
- 管理APIと会員APIへメール、LINE subject、認証情報を追加しない。
- desktop/mobileで長い説明やボタンが横にはみ出さない。
