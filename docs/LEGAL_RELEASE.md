# 法務文書の初回公開手順

初期運用ではCMSを使わず、利用規約とプライバシーポリシーを `packages/domain/src/legal.ts` でコード管理する。画面の本文と登録時に記録する同意バージョンは同じ定義を使う。

## 必要な確定事項

運営者と法務確認者が、少なくとも次の内容を含む審査済み文書を用意する。

- 運営者名、所在地、問い合わせ先
- 無料・有料サービスの内容、禁止事項、利用停止、免責、知的財産、準拠法・管轄
- 料金、自動更新、解約、返金の条件
- 取得情報、利用目的、外部送信、委託・第三者提供、保持・削除、開示請求、Cookie等の扱い
- LINE、Supabase、Stripe、Resend、監視基盤で扱う情報と外部送信先
- 発効日と、各文書の重複しないバージョン

## 反映手順

1. `packages/domain/src/legal.ts` の本文を審査済み文書と一致させる。
2. `consentVersions` に新しい固有バージョンを設定する。過去に使ったバージョンを再利用しない。
3. 両文書の `effectiveDate` を `YYYY-MM-DD` で設定し、`status` を `PUBLISHED` にする。
4. 表示本文、登録画面のリンク、同意バージョンをレビューする。
5. `pnpm build` と `node scripts/check-production-guard.mjs` を実行する。本文、バージョン、施行日、公開状態が揃わない限り、本番APIは起動を拒否する。

同意履歴は追記専用であり、新版の公開で過去の同意を書き換えない。一般募集開始後の改定で既存会員に再同意を求める場合は、適用日と必須化の条件を決定してから別機能として実装する。
