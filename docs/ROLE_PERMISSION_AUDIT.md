# 実装済み機能・権限監査

確認日: 2026-09-16

## 2026-09-16 対応状況

- 管理者による`MEMBER`・`EXPERT`・`EDITOR`・`OPERATOR`のロール変更を実装した。ADMINは管理者継続運用でのみ追加する。
- 変更時の対象メール再入力、理由、現在ロール一致、行ロック、セッション失効、監査追記を実装した。
- 今後の担当レースまたは有効なWIN5商品が残るEXPERTの解除拒否を実装した。
- ADMINにEXPERT専用WIN5リンクを表示する不整合を解消し、無料速報とスタッフ権限管理をナビゲーションへ追加した。
- OPERATORがAAL1でWIN5画面を開いた場合、APIエラーになる前にセキュリティ設定へ案内する。
- OPERATOR向けに、秘密値や設定入力値を表示しない運用・外部連携状態の読取画面を追加した。
- `EDITOR`はCMSを導入するまで予約ロールのままとし、専用操作機能は追加していない。
- 今後の未終了レースとJST当日以降の有効なWIN5を、別の有効なEXPERTへ一括移管する機能を追加した。公開済み版と過去履歴は変更しない。
- EXPERT/EDITOR/OPERATORの利用停止・再開を追加した。ロールと会員設定を保持し、業務担当・配信予約・契約・閲覧権限が残る停止は拒否する。
- 月額・1日利用の申込をMEMBERだけに限定し、有料会員状態が残るMEMBERのスタッフ昇格も拒否する。
- 管理者継続運用に、別管理者の停止・再開・降格を追加した。自己操作を禁止し、変更後も有効な管理者2名以上と本番用の主・予備MFAをDBトランザクション内で保護する。

本書は仕様上の予定ではなく、現在のWeb、API、ドメイン権限関数、結合テストから確認できる実装を整理する。ロールはDBに保存した`MEMBER / EXPERT / EDITOR / OPERATOR / ADMIN`をサーバーが使用し、クライアントから送信されたロールは信用しない。AALはローカルセッションまたはSupabaseの署名済み認証情報から取得する。

## 利用者区分

無料会員、創設会員、通常月額会員、1日利用者はすべて`MEMBER`である。有料範囲はロールではなく、開始・終了時刻、対象日、失効状態を持つ有限期間の閲覧権限で判定する。

| 区分 | 現在できること | 制限 |
| --- | --- | --- |
| 未登録者 | ホーム、対象レース一覧、WIN5一覧と無料メタデータ、公開成績、料金、規約・プライバシーの閲覧。メールまたはLINEの無料登録、メール確認、ログイン、パスワード再設定 | 予想本文、評価馬、馬番、理由、詳細見解、パドック評価、会員通知を取得できない |
| 無料会員 | アカウント・同意履歴・通知設定、LINE連携、予備メール、会員通知、登録特典、契約確認、請求問い合わせ、条件を満たす場合の退会。有料申込と1日利用申込 | 公開予想は版・公開時刻などのメタデータだけ。無料速報も現在は公開版メタデータだけで、馬名・馬番・理由・音声・検証本文を返さない |
| 創設・通常月額会員 | 有効期間中の有料WIN5紙面とパドック直前予想、公開版履歴、契約・支払履歴、次回更新停止 | 管理・入力操作は不可。クラウド試験は請求なし、本番の外部決済はStripe本番設定と公開モードが揃うまで利用不可 |
| 1日利用者 | 対象日のWIN5紙面とパドック直前予想。対象日の有限期間だけ有料本文を取得 | 対象日以外と有効期間外はロック。対象日のWIN5初版公開時刻を開始時刻にする処理を実装済み |

## スタッフロール

| ロール | 認証条件 | 現在できること | できないこと・境界 |
| --- | --- | --- | --- |
| EXPERT 専門家 | AAL2必須。通常レースはDB上の担当、WIN5は商品担当を照合 | 担当レースの事前評価・パドック評価・履歴、最終予想下書き、プレビュー、初版公開。担当WIN5の5レース評価、中心馬・相手候補・注目馬・危険馬、見解、プレビュー、初版公開 | 担当外レース、会員・決済・設定・結果管理は不可。公開済み予想の訂正版公開は既定でADMINのみ |
| EDITOR 編集担当 | 通常ログイン。AAL2必須ロールではない | 共通の本人アカウント・セキュリティ画面 | 専用API、管理画面、CMS権限は未実装。CMS延期に伴う予約ロール |
| OPERATOR 運営担当 | 通常の運用APIはAAL1可。WIN5の設定・入力・公開・結果だけ明示的にAAL2必須 | 管理ダッシュボード、一般問い合わせの担当・優先度・期限・回答管理、開催日・レース・出走馬・担当専門家、CSV/JRA-VAN取込、対象レース告知、無料速報・音声・登録特典、配信予約、通知確認・再送、障害確認、運用アラート対応、通常結果取込・確定、SNS共有候補。AAL2完了時はWIN5商品・評価・初版公開・結果確定 | 秘密設定更新、通知テスト送信、メール配信停止解除、会員・監査、権限付与、課金管理、流入施策、バックアップ、本番準備、管理者管理、訂正版公開は不可 |
| ADMIN 管理者 | AAL2必須 | OPERATORの全機能。全レースの専門家入力、通常予想・WIN5の訂正版公開、Turnstile・LINE・メール・Stripe・料金・緊急停止設定、通知テスト、会員・監査、スタッフロール・有限期間権限付与、請求対応、流入・登録フォロー、バックアップ・本番準備、退会記録、管理者昇格・停止・再開・降格、予備MFA管理 | 自分自身の停止・降格、継続性を損なう管理者変更、公開済み予想・確定結果・監査履歴の上書きや物理削除は不可。実際の返金、SNS自動投稿、馬券購入・自動投票は未実装 |

| 有料予想本文 | 有効なMEMBER権限、担当EXPERT+AAL2、ADMIN+AAL2。WIN5はOPERATOR+AAL2も可 | 通常予想は担当EXPERT+AAL2またはADMIN+AAL2。WIN5初版は担当EXPERT、ADMIN、OPERATORのAAL2。訂正版はADMIN+AAL2 |
| レース・出走馬・担当 | ADMIN+AAL2 / OPERATOR | ADMIN+AAL2 / OPERATOR |
| 無料速報・登録特典・配信予約 | ADMIN+AAL2 / OPERATOR | ADMIN+AAL2 / OPERATOR |
| 通知運用 | ADMIN+AAL2 / OPERATOR | 再送はADMIN+AAL2 / OPERATOR。テスト送信とメール停止解除はADMIN+AAL2 |
| 通常レース結果 | 公開成績は全員、管理詳細はADMIN+AAL2 / OPERATOR | ADMIN+AAL2 / OPERATOR |
| WIN5結果 | 公開成績は全員、管理詳細はADMIN+AAL2 / OPERATOR+AAL2 | ADMIN+AAL2 / OPERATOR+AAL2 |

## 確認できた権限制御

- 通常レースの評価・予想は担当IDとAAL2をAPIで再検証し、クライアントが`role`を追加しても入力エラーにする。
- 無料会員・未認証者向け予想レスポンスから評価馬、馬番、理由、詳細見解、訂正理由を除外する。
- 有料閲覧は開始時刻以上、終了時刻未満、未失効、対象日一致をサーバーで判定する。
- 公開版、凍結評価、確定結果、監査履歴は追記専用で、アプリだけでなくPostgreSQLでも更新・削除を拒否する。
- 訂正は旧版を保持した新版追加で、発走後は公開・訂正できない。
- 管理用秘密値は設定済みかだけを返し、APIレスポンスと監査ログへ平文を出さない。

## 現在の不足・不一致

1. **EDITORは予約ロール。** CMSを初期公開から外した方針により、ロール変更対象には含むが、記事・動画・音声・予約公開の専用権限はない。

## 外部設定が揃うまで完了しない機能

- Supabase本番認証・MFA、正式ドメインでの認証フロー
- Cloudflare Turnstileの公開hostname確認
- LINE LoginとMessaging APIの実アカウント疎通
- Resendの送信ドメイン・Webhook実疎通
- Stripe Checkout・Webhook・実決済リハーサル
- JRA-VAN契約情報を使用したライブ取得と実データ開催日リハーサル

これらはコード上の設定・検証境界まで実装済みだが、現在のローカル試験だけで本番利用可能とは判定しない。
