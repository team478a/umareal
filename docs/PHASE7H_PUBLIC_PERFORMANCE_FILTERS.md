# Phase 7H 公開成績の条件別集計

## 目的

公開済みのパドック直前予想について、結果が良かったレースだけでなく全公開対象を、期間・競馬場・芝／ダートで検証できるようにする。WIN5成績とは引き続き分離する。

## 実装範囲

- `GET /results/stats`に任意の`dateFrom`、`dateTo`、`venue`、`surface`を追加する。
- 期間は両端の指定を必須とし、最大366日とする。無指定では従来どおり全期間を集計する。
- レースごとの最新結果版だけを対象とし、結果訂正前の評価を重複して数えない。
- 会員画面に絞り込みと、信頼度・競馬場・芝ダート・月別の内訳を表示する。
- 集計条件をAPI応答に明示し、表示中の母集団を利用者が確認できるようにする。

## 非対象

- 払戻、回収率、利益、購入金額の集計
- WIN5成績との混合
- DB migration
- 外部サービス通信
- 本番deploy

## 検証

- Domain: 期間境界、不完全な期間、逆転期間、366日超過、非公開fieldの拒否
- Integration: 期間・競馬場・芝ダートの複合条件、最新結果版、不正query拒否
- E2E: desktop/mobileの絞り込み、内訳表示、横スクロールなし
