# WIN5 Phase 5 公開フロー検証

## 第1区間の目的

管理者が実際の画面だけを使い、WIN5紙面の準備から初版公開まで完了できることをPCとスマートフォンで継続検証する。

## 完了範囲

- WIN5予想枠を作成する。
- 全体総評と公開設定を保存する。
- 対象日の5レースを指定する。
- 各レースで中心馬と相手候補、選定理由、展開見解、短評を保存する。
- 5レースが揃った状態で公開内容を確認し、初版を公開する。
- 公開版、対象5レース、各レースの評価馬がDBへ保存されたことを確認する。
- PCとスマートフォンで横方向の画面崩れがないことを確認する。
- 有料会員が公開紙面と公開履歴を閲覧し、通知履歴から紙面へ移動できることを確認する。

## 検出して修正した不具合

Webの同一オリジンAPI中継が`PUT`を公開していなかったため、WIN5の対象レース保存が実画面ではHTTP 405になっていた。API自体の統合試験はAPIへ直接接続するため、この欠落を検出できていなかった。

中継へ`PUT`を追加し、ブラウザから5レースを保存して公開するE2Eを回帰試験に追加した。

## 残区間

- 想定同時閲覧・公開操作の負荷試験
- 認可、情報非開示、締切、再送、改ざん防止のセキュリティ総点検
- 前日準備、当日公開、通知、結果確定までの開催日リハーサル
- 本番環境への配備と実運用確認（別承認）
