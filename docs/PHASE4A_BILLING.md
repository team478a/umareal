# Phase 4A 料金プラン・契約ライフサイクル

## 実装範囲

- 管理設定で創設会員、通常会員、1日利用の税込価格、創設会員販売可否・上限、支払猶予日数、新規購入停止を管理
- ローカルtest transportによる月額・1日利用の申込と有限期間閲覧権限の同時付与
- UUIDのIdempotency-Key、会員単位ロック、DB一意制約による二重契約・二重申込防止
- 解約予約後も支払済み期間終了まで閲覧可能
- 本人の契約・1日利用・支払履歴と、ADMIN+AAL2の全体管理画面
- 理由付きの支払失敗・回復試験、追記専用の支払試行・請求イベント・監査ログ
- 本番でローカルtest transportを拒否

## 開発用の扱い

価格は仕様書初期案の1,980円、2,980円、980円。創設会員上限は100、支払猶予は0日を初期値とするが、正式販売条件ではない。月額期間は申込UTC時刻から暦1か月で、翌月に同じ日がない場合は月末へ丸める。1日利用は指定JST日の00:00以上、翌日00:00未満。

## 対象外

Stripe等の外部決済、カード情報、Webhook、自動更新ジョブ、返金、領収書、クーポン、試用期間、プラン変更、正式な特商法表示・利用条件。本番接続は別フェーズで正式条件を決めてから行う。
