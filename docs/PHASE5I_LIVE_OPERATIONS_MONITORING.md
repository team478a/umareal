# Phase 5I 開催日ライブ監視

開催日運用ボードへ自動更新と情報鮮度の表示を加え、開催中に古い状態を見続ける可能性を下げた。

## 実装範囲

- 表示中の運用ボードを30秒間隔で自動更新する。
- ブラウザーのタブが非表示の間は定期取得を止め、再表示時に即時更新する。
- 最終更新時刻、自動更新中、更新中、更新失敗、90秒以上経過した情報を区別して表示する。
- 「今すぐ更新」で手動更新する。
- 発走までの残り時間を1秒ごとに更新し、30分以内と発走時刻経過の表示を切り替える。
- 日付切替や連続更新の応答順が逆転した場合、古い応答を破棄する。
- スマートフォンでは接続状態と更新ボタンを縦に配置し、44px以上の操作領域を確保する。

## 境界

30秒・90秒は開発初期値である。WebSocket、Server-Sent Events、プッシュ通知、外部監視サービス、バックグラウンドタブでの常時ポーリング、実LINE疎通、本番デプロイは含めない。
