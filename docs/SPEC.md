# 競馬ファン向け会員制メディア Codex開発仕様書

作成日：2026年9月12日

対象：中央競馬・土日開催を中心とした会員制Webメディア

状態：MVP開発着手用

本サービスは、レース前日に公開するWIN5紙面予想と、当日の馬の状態を反映するパドック直前予想を提供する会員制競馬メディアである。

## 0. Codexへの最初の指示

この文書を本プロジェクトの実装基準とする。最初から全機能を一括実装せず、後述のフェーズ順に進めること。

作業開始時に以下を実施する。

1. リポジトリ全体、README.md、AGENTS.md、既存設定、未コミット変更を確認する。

2. 本仕様と既存実装の差分を整理し、変更対象ファイルと実装順を短く提示する。

3. 不明点のうち開発を止める事項だけ質問する。本文に既定値がある項目は質問せず採用する。

4. 1フェーズずつ実装し、各フェーズで typecheck、lint、test、build を通す。

5. データ消失を伴う処理、公開済み予想の更新、決済本番接続、本番デプロイは勝手に行わない。

6. 完了報告には、変更内容、確認方法、テスト結果、未対応事項を記載する。

クラウド試験は`CLOUD_STAGING`として一般公開と分離する。Basic認証は使用せず、`no-store`と`X-Robots-Tag: noindex, nofollow`でキャッシュと検索登録を拒否する。管理機能と会員情報はアプリのログイン・ロール・AAL2で保護する。LINE Login、LINE通知、実Stripe決済は停止し、課金は請求なしのtest transportだけで月額・1日利用・解約・権限反映を確認する。開発版法務文書はこのテスト環境だけで使用できる。`FREE_REGISTRATION`と`FULL`の本番起動では引き続き公開済み法務文書を必須とする。

### 最優先の完成条件

次の2点を本システムの中核とする。

- 専門家がスマートフォンで、全出走馬のパドック評価から最終公開まで3分以内で操作できる。

- 一度公開した予想は上書き・削除できず、訂正も履歴として残り、外れを含む全予想が成績に反映される。

## 1. サービス概要

本サービスは、三国谷氏による前日のWIN5事前分析と当日のパドック診断を分離して公開し、両方を有料会員へ提供する会員制Webメディアである。

予想だけを販売する短期サービスではなく、記事・動画・音声・馬の物語を通じてファン化を進める。ただしMVPでは予想配信の安定運用を最優先とする。

### サービスが行うこと

- 無料会員、有料月額会員、1日利用者の登録・認証・権限制御

- レース情報、前日WIN5紙面予想、事前評価、パドック診断、パドック直前予想の公開

- 最終予想や評価変更のLINE通知

- WIN5とパドック直前予想を分離した馬の評価結果、公開履歴の保存・表示

- 記事、動画、音声コンテンツの公開

- 会員、売上、通知、予想運用を確認する管理画面

- 管理者によるスタッフロール管理。確認済みメールの再入力、変更理由、セッション失効、監査履歴を必須とし、担当中の専門家解除を防止する。担当交代時は今後のレースとWIN5担当を別の専門家へ一括移管し、過去の公開版と履歴を維持する。スタッフ利用停止はロールと会員設定を保持し、担当・配信予約・契約・閲覧権限が残る場合は拒否する。管理者の停止・降格は別の管理者だけが行え、変更後も有効な管理者2名以上と本番MFA復旧経路を維持する

### サービスが行わないこと

- 馬券販売

- 馬券購入代行

- 自動投票

- 賭け金の預かり

- 払戻金の受領・分配

- 的中や利益の保証

- AIによる自動パドック判定

- AIによるWIN5評価馬や買い目の自動生成

- 地方競馬、海外競馬、ネイティブアプリ対応

中心馬、相手候補、注目馬、危険馬とレース見解を情報提供として表示する。券種、組み合わせ、購入金額は指定せず、購入判断と購入操作は利用者本人が行う。

## 3. 会員区分と料金

金額は税込の初期案とし、管理画面または設定値で変更可能にする。金額をソースコードへ直接埋め込まない。

| 区分 | 初期料金 | 有効期間 | 主な閲覧範囲 |
| --- | --- | --- | --- |
| 無料会員 | 0円 | 退会まで | 一部記事、無料公開、結果、公開通知 |
| 1日利用 | 980円 | 対象日のWIN5初版実公開時刻〜翌日0:00 JST。WIN5商品がない日は対象日0:00開始 | 対象日のWIN5紙面・パドック直前予想・解説 |
| 創設会員 | 月額1,980円 | 月次自動更新 | 通常月額と同等。販売上限100〜200人を設定可能 |
| 通常月額 | 月額2,980円 | 月次自動更新 | 全有料予想、直前情報、対象コンテンツ |

### 3.1 アクセス判定

- 画面表示だけでなく、APIとデータ取得時にも権限を確認する。

- 支払済み期間、1日利用対象日、公開範囲、公開時刻をすべて満たした場合だけ本文を返す。

- 無料会員へ中心馬、相手候補、注目馬、危険馬、具体的な馬番、選定理由、詳細なレース見解、パドック評価を返さない。

- WIN5について無料会員へ返すのは、公開状態、対象日、対象5レースと、公開設定で許可した全体信頼度までとする。評価馬、馬番、理由、詳細見解、総評、訂正理由は返さない。

- 1日利用は支払完了と閲覧開始を分離する。WIN5初版公開前に購入された場合は、初版の実公開時刻まで有限期間権限の開始を待機する。

- 月額解約は次回更新停止とし、支払済み期間の終了までは利用可能とする。

- 決済失敗時は猶予期間を設定可能にし、期間終了後に有料権限を停止する。

- 管理者による無期限の権限付与は禁止し、開始日・終了日・理由・実行者を必須にする。

## 4. 利用者と権限

| ロール | 主な権限 | 禁止事項 |
| --- | --- | --- |
| 未登録者 | LP、公開記事、料金、規約の閲覧 | 会員情報・有料予想の取得 |
| 無料会員 | 無料情報、公開後結果、通知設定 | 有料予想本文の取得 |
| 有料会員 | 契約範囲の予想・コンテンツ閲覧 | 管理・入力操作 |
| 専門家 | 担当レースの評価入力、担当WIN5商品の選択入力、プレビュー、公開申請・公開 | 会員・決済・全体設定の操作 |
| 編集担当 | 記事、動画、音声、公開予約 | 決済、専門家経歴証跡の改変 |
| 運営担当 | レース、結果、通知、問い合わせ、訂正承認 | 権限管理、機密設定 |
| 管理者 | 全設定、権限、契約、監査確認、緊急停止 | 公開版の物理削除 |

- 管理者と専門家は二段階認証を必須にする。

- ロールだけでなく、担当レースおよび担当WIN5商品単位でも操作範囲を制限する。

- WIN5の商品設定、入力、プレビュー、公開、結果確認はADMIN、OPERATOR、担当EXPERTの許可された操作に分け、すべてAAL2を必須にする。訂正版公開は管理画面の公開ルールに従い、既定ではADMIN+AAL2に限定する。変更はADMIN+AAL2、設定revision、変更理由を必須とし監査する。

- 管理者の代理操作は、対象利用者・理由・実行者を監査ログへ残す。

## 5. 主要ユーザーフロー

### 5.1 会員登録

1. LPまたはLINEから登録画面を開く。

2. メールアドレスまたは外部認証で本人を識別する。

3. 20歳以上、利用規約、プライバシーポリシーへの同意を得る。

4. 無料会員を作成する。

5. LINE連携を案内する。未連携でもWeb利用は可能にする。

6. プラン購入後、決済Webhookの成功確認をもって有料権限を有効化する。

同意履歴には、利用者ID、文書種別、文書バージョン、同意時刻、取得元を保存する。

### 5.2 予想公開

WIN5紙面とパドック直前予想は別の公開版として運用する。

#### WIN5紙面予想

1. 運営が対象日、担当専門家、公開予定時刻、公開範囲と対象5レースを設定する。

2. 担当者が各レースの中心馬、相手候補、注目馬、危険馬、選定理由、信頼度、展開見解を入力する。

3. サーバーが評価区分の重複、中心馬数、出走状態を検証する。

4. プレビューで5レース、評価、公開範囲、警告と締切を確認する。

5. 対象5レースの最小発走時刻より前に、公開版・監査・通知イベントを同一トランザクションで追記する。

6. 訂正は旧版を残して新版を追加し、締切後は管理者も公開できない。

#### パドック直前予想

1. 管理者が開催日・対象レース・担当専門家・公開予定時刻を登録する。

2. 専門家が事前評価を入力し、必要に応じて事前予想を公開する。

3. 当日パドックで全頭を評価する。

4. 事前評価とパドック評価を比較し、最終本命・対抗・穴候補・危険馬・評価UP・評価DOWN・信頼度・見送りを決める。

5. プレビュー画面で馬番、馬名、公開範囲、発走時刻、未入力を確認する。

6. 公開ボタン押下時に新しい公開版を作り、会員画面へ反映する。

7. 通知対象を確定し、LINE送信キューへ登録する。

8. 発走後は新規公開・訂正を禁止する。

パドック評価や結果によって前日のWIN5公開版を書き換えない。両予想の判断が異なる場合は、パドック直前予想側に独立した説明を保存・表示する。

### 5.3 結果確定

1. レース結果をCSVまたは管理画面から取り込む。

CSVは1レース単位または複数レース単位で、全出走馬の馬番、結果状態、着順、人気、確定単勝だけを受け付ける。複数レース取込は内部標準形式とJRA-VAN連携ブリッジ形式を取込元アダプターで共通形式へ変換し、開催日・競馬場・レース番号で照合する。JRA-VAN連携ブリッジは復号済みSEをWindowsのオフラインCLIで厳格検証し、内容順に依存しないUTF-8 CSVとSHA-256 manifestを生成する。一括出力のmanifestを結果プレビューへ指定した場合は、results.csvのSHA-256、対象日、行数、確定レース数をAPIで再検証する。1件でも不正または競合がある場合は全件を反映しない。差分プレビュー後の確定は取込元、形式版、ファイル指紋と検証済みbundle情報を監査して結果下書きへ反映し、結果確定と評価・通知の生成はレースごとの別操作にする。同一提供元・同一指紋の確定済みファイルは重複拒否し、同じ対象レース集合の変更ファイルは前回取込を保持した公式訂正として扱う。払戻、券種、買い目、購入金額は取り込まない。JV-Link利用キーと固定長データはCLI、CSV、manifest、Web/APIへ渡さない。

同一開催日のJRA-VAN一括出力を再取得した場合、管理画面へ渡す前に前回bundleと今回bundleをそれぞれ完全検証し、成果物SHA-256を比較する。変更なし、新たな確定結果の追加、同一レース集合の結果訂正候補、レース・出走馬変更、確定済みレースの消失を区別する。比較CLIは自動取込・自動確定を行わず、必要な管理画面プレビューと人手確認を案内する。

2. 取消・除外・競走中止・レース中止を確認する。

3. 管理者が内容を確認して結果を確定する。

4. 公開時点の馬評価に基づき、本命馬の着順と勝ち馬候補内選出を判定する。

5. 全公開予想の成績へ反映する。外れた予想も削除しない。

WIN5結果では5レースそれぞれの最新確定結果版と、締切までに公開された最新のWIN5商品版を固定する。5レースすべての勝ち馬が選択馬に含まれる場合だけ完全的中とし、通常馬券の成績とは別に集計する。取消、除外、中止、返還の規則で自動確定できない場合は`REVIEW_REQUIRED`とする。

## 6. レース 出走馬管理

### 6.1 必須項目

開催日、競馬場、レース番号、レース名、クラス、距離、芝／ダート、右左、発走予定時刻、馬場状態、天候、レース状態を保存する。

出走馬は、馬ID、馬番、枠番、馬名、性齢、斤量、騎手、調教師、単勝オッズ、人気、取消・除外状態を保存する。

### 6.2 初期データ取込

- MVPでは管理者によるCSV取込と手動補正を実装する。

- CSVフォーマットはサンプルファイルとバリデーション結果を用意する。

- 同一の開催日・競馬場・レース番号を重複登録しない。

- 同一レースの馬番を重複登録しない。

- 再取込は差分プレビュー後に確定する。

- 正式データ提供元への移行に備え、RaceDataProvider インターフェースを設ける。

- 結果取込はResultDataProviderで内部標準CSVとJRA-VAN連携ブリッジCSVを分離し、提供元・形式版・ファイル指紋を監査する。

- JRA-VANの開催準備はmanifest、レースCSV、レース別出走馬CSVをサーバーで再検証し、差分プレビュー後に開催日単位の1トランザクションで反映する。投入前CLIは全成果物の指紋、正規形式、レース対応を検査して診断レポートを保存する。manifestに結果CSVがあっても結果確定へ直結させない。

### 6.3 状態

SCHEDULED / ACTIVE / DELAYED / FINISHED / CANCELLED

発走時刻変更時は、締切時刻と通知予定を再計算し、必要に応じて会員へ案内する。

## 7. 事前評価 パドック診断

### 7.1 事前評価

各出走馬に対して、事前点数、事前順位、印、短評を保存する。点数範囲は0〜100を初期値とする。

### 7.2 パドック評価項目

各項目を1〜5で選択し、判断不能も許可する。

- 馬体の張り

- 歩様・踏み込み

- 毛艶

- 気合・集中力

- 発汗・落ち着き

追加で、総合変化を 大幅UP / UP / 据え置き / DOWN / 大幅DOWN / 判断不能 から選ぶ。

短評は定型文候補、自由入力、端末の音声入力を利用できる通常テキスト欄を用意する。

### 7.3 スマートフォン入力画面

- 1画面に1頭または少数頭を表示し、左右スワイプまたは「次の馬」で進める。

- 片手操作を前提に、主要ボタンの高さは最低44pxとする。

- 馬番、馬名、事前順位、事前印を常時確認できる。

- 入力ごとに端末へ一時保存し、通信回復時に同期する。

- 同期状態を 保存済み / 送信中 / 未送信 / 競合 で表示する。

- 全頭の入力進捗と未入力馬を固定表示する。

- 公開画面へ進む前に未入力を警告する。判断不能は入力済みとして扱う。

- 同一馬を複数端末で編集した場合は、黙って上書きせず競合を表示する。

## 8. パドック直前予想とWIN5紙面予想

### 8.1 パドック直前予想の保存項目

- 本命、対抗、単穴、連下、穴候補、危険馬

- レース信頼度 S / A / B / C

- 信頼度 S / A / B / C または見送り

- 評価UP馬、評価DOWN馬と変更理由

- 総評

- 公開範囲

- 公開予定時刻、公開時刻、発走予定時刻

### 8.2 馬評価

最終本命、対抗、穴候補、危険馬、評価UP馬、評価DOWN馬、選定理由、パドック診断、最終見解を保存する。券種、組み合わせ、点数、購入金額は入力・計算・公開しない。

### 8.3 見送り

- 見送りを正式な最終判断として保存できる。

- 見送り時は評価馬を公開しない。

- 本命馬成績の分母から除外し、見送り数・見送り率を別表示する。

### 8.4 WIN5紙面予想

予想種別は`WIN5_PREVIEW`とし、既存の1レース予想は概念上`PADDOCK_RACE`として扱う。既存予想を置換せず、WIN5を単一のraceIdへ紐づけない。

商品基本情報として対象開催日、タイトル、担当専門家、公開範囲、公開予定時刻、初版実公開時刻、全体信頼度、総評を保存する。

対象順1〜5の各レースには、競馬場、レース番号、発走予定時刻、既存raceId、中心馬、相手候補、注目馬、危険馬、選定理由、レース信頼度、展開見解、短評を保存する。同じ対象順または同じレースを商品内で重複させず、同じ馬へ複数の評価区分を設定しない。

会員画面はWeb上の新聞風レイアウトとし、PDF生成と印刷専用機能はMVPに含めない。5レースの後に全体信頼度、総評、公開時刻、訂正状態と注意事項を表示する。

## 9. 公開版 訂正 改ざん防止

### 9.1 状態

DRAFT / READY / PUBLISHED / CORRECTED / CLOSED / CANCELLED

### 9.2 不変条件

- PUBLISHED 以降の公開版レコードは更新・削除しない。

- 訂正時は旧版を残し、新しい prediction_versions を追加する。

- 公開時に、予想本文、馬評価、理由、見解、対象プランをスナップショット化する。

- 各版に連番、公開者、公開時刻、訂正理由、直前版IDを保存する。

- 発走予定時刻以降は訂正版を作成できない。

- WIN5は対象5レースの最小発走時刻以降、初版・訂正版を作成できない。

- 管理者であっても物理削除APIを提供しない。

- 会員画面には公開時刻と「訂正」表示を出し、旧版も確認可能にする。

実装はアプリケーション制御だけに依存せず、データベース制約またはトリガーでも公開版の更新・削除を拒否する。

WIN5公開版は5レース、出走馬、中心馬、相手候補、注目馬、危険馬、理由、信頼度、展開見解、公開範囲を内容全体のスナップショットとして保持する。結果判定は締切までに公開された最新の商品版IDへ固定し、当日のパドック評価、最新下書き、結果から公開版を変更しない。

### 9.3 監査ログ

作成、更新、公開、訂正、返金、権限変更、データ取込について、以下を保存する。

- 実行者IDとロール

- 操作種別

- 対象種別と対象ID

- 実行日時

- 変更前後の差分または参照可能なスナップショット

- 理由

- リクエストID

- IPアドレスとユーザーエージェント（個人情報方針に従い保存期間を設定）

- ADMIN+AAL2は、通常予想、WIN5予想、課金状態の通知をログイン中の管理者本人へテスト送信できる。宛先はサーバーが本人の有効なLINE連携または確認済みメールに固定し、公開版、会員向け通知、配送、支払・契約・閲覧権限を変更しない。

- 公開からLINE送信開始まで原則60秒以内。

## 12. レース結果 成績検証

パドック直前予想とWIN5は別の結果・成績体系で管理し、同じ指標へ混在させない。買い方と購入金額を指定しないため、馬券的中率、払戻額、回収率、利益額は計算しない。

### 12.1 保存項目

- 着順、人気、確定オッズ

- 取消、競走除外、競走中止、レース中止

- 公開版ごとの中心馬・本命馬、相手候補、評価UP／DOWN馬、危険馬の評価結果

- 本命馬の着順

- 評価UP／DOWN馬の結果

- 集計ルールバージョン

### 12.2 公開指標

- 公開レース数、本命馬1着数・率、本命馬連対率、本命馬複勝率

- 本命複勝率、本命連対率

- 評価UP馬好走率、評価DOWN馬凡走率

- 信頼度別、競馬場別、芝／ダート別、月別成績

- 見送り数、見送り率

### 12.3 計算式

```text
本命馬1着率 = 本命が1着のレース数 ÷ 集計対象の本命を出したレース数 × 100
本命複勝率 = 本命が3着以内のレース数 ÷ 本命を出したレース数 × 100
本命連対率 = 本命が2着以内のレース数 ÷ 本命を出したレース数 × 100
```

- 的中したレースだけでなく、公開した全対象予想を集計する。

- 見送りは見送り数・見送り率へ含め、本命馬成績の分母から除外する。

- 出走取消、競走除外、レース中止は定義済みルールに従い除外または返還処理する。

- 結果取得失敗は自動確定せず REVIEW_REQUIRED にする。

- 集計済み数値だけでなく、再計算できる元データを保存する。

結果状態は WAITING / IMPORTED / REVIEW_REQUIRED / CONFIRMED とする。

### 12.4 WIN5結果・成績

WIN5確定結果には対象5レースの勝ち馬、中心馬または相手候補への勝ち馬選出、中心馬の着順、5レース全選出状態、結果確認者・時刻、集計ルール版を保存する。

```text
WIN5候補内選出 = 勝ち馬が固定した公開版の中心馬または相手候補に含まれる
WIN5全選出 = 対象5レースすべてでWIN5候補内選出が成立する
WIN5候補内選出率 = 候補内選出レース数 ÷ 集計対象レース数 × 100
```

公開指標は公開回数、対象レース数、勝ち馬候補内選出数・率、5レース全選出回数、中心馬1着数・率、中心馬連対率、中心馬複勝率とする。外れた予想も分母へ含め、削除しない。

`DOUBLE_HIT`やプラス収支の判定は行わない。WIN5とパドック直前予想の双方で良い評価結果が出た場合も、確認できる事実をそれぞれ個別に表示する。

取消、除外、中止、返還の正式規則は設定可能な集計ルール版として保留する。自動計算できない状態は`REVIEW_REQUIRED`とし、的中表示、成績反映、SNS共有画像生成を禁止する。

### 18.1 API共通ルール

- エラー形式を統一し、code / message / requestId / details を返す。

- 外部Webhookの署名を検証する。

- 作成・公開・訂正・返金APIは冪等キーを受け付ける。

- 日時はAPI上ISO 8601で返し、タイムゾーンを明示する。

- 一覧APIはページネーションを必須にする。

### 22.1 必須ユニットテスト

- 通知対象と無料会員向け内容制御

- Webhook冪等処理

- WIN5の5レース全候補内選出、候補内選出数・率、本命馬1着・連対・複勝

- 1日利用の前日閲覧開始、最小発走時刻による締切、無料会員DTO、WIN5訂正版の版番号

- WIN5の取消・除外・中止・返還。未確定規則は`REVIEW_REQUIRED`

### 22.2 必須結合テスト

- 会員登録から有料権限有効化

- 1日利用購入と対象日判定

- 専門家入力から最終公開・LINEキュー登録

- 公開後の更新・削除拒否

- 訂正版追加と旧版保持

- 結果確定から全成績再計算

- 決済失敗から権限停止・復旧

- WIN5商品作成、対象5レース、馬評価入力、プレビュー、公開版、訂正版、旧版保持

- WIN5公開後の直接更新・削除拒否、通知キュー登録、1日利用の前日閲覧

- WIN5結果取込、5レース全候補内選出、分離成績、SNS共有用の事実データ生成

### 22.3 必須E2E

1. 無料会員は有料予想本文をAPIから取得できない。

2. 有料会員は有効期間内の予想を閲覧できる。

3. 専門家は担当外レースを編集できない。

4. 全頭評価から最終公開までスマートフォンで完了できる。

5. 公開済み予想を管理者でも上書き・削除できない。

6. 訂正すると旧版・訂正版・理由・時刻が表示される。

7. 発走後は公開と訂正が拒否される。

8. 同一Webhookを複数回受信しても契約・通知・売上が重複しない。

9. 外れた予想も成績へ反映される。

10. LINE失敗後もWeb上の予想公開は維持される。

11. 管理者が対象5レースを設定し、担当専門家が中心馬、相手候補、注目馬、危険馬を登録できる。

12. 同じ馬へ複数の評価区分を設定できず、各レースの中心馬が1頭に制限される。

13. 有料会員と対象日の1日利用者は前日にWIN5紙面を閲覧できる。

14. 無料会員APIは中心馬、相手候補、注目馬、危険馬、馬番、理由、詳細見解、パドック評価を返さない。

15. 公開済みWIN5を上書き・削除できず、訂正時も旧版・理由・時刻が残る。

16. 最初の対象レース締切後は初版・訂正版とも拒否される。

17. パドック予想の更新がWIN5公開版を変更しない。

18. 候補外となったWIN5予想も分離成績へ反映される。

19. 結果未確定または`REVIEW_REQUIRED`ではSNS共有画像を生成できない。

## 23. 障害 例外処理

| ケース | システム動作 | 運営対応 |
| --- | --- | --- |
| 専門家が間に合わない | 未確定または見送り表示。前の下書きを自動公開しない | 配信中止理由を登録し案内 |
| LINE送信失敗 | Web公開は維持し自動再試行 | 失敗一覧から確認・再送 |
| 通信切断 | 入力を端末へ一時保存し再同期 | 同期状態と競合を確認 |
| 発走時刻変更 | 締切・通知時刻を再計算 | 必要時に会員通知 |
| 取消・除外 | 対象馬を無効化し評価結果を再確認 | 公式結果を確認して確定 |
| レース中止 | 予想を中止扱い、成績対象外 | 1日利用の返金基準に従う |
| 結果取得失敗 | 自動確定せず確認待ち | 公式結果を確認し手動確定 |
| 決済通知重複 | 同一外部IDを無視 | 監査ログで確認 |
| 公開後の誤記 | 新しい訂正版を作成し旧版も表示 | 理由入力、必要なら再通知 |
| WIN5の対象5レース不足・重複 | 公開前確認と確定を拒否 | 対象順、レース、評価馬、中心馬を修正 |
| WIN5公開予定超過 | Web公開を自動確定せず運用警告 | 内容と締切を確認して手動公開または中止 |
| WIN5例外結果 | `REVIEW_REQUIRED`として的中・共有を停止 | 公式結果と適用する集計ルール版を確認 |

## 24. MVP受入基準

以下をすべて満たした時点でテスト運用開始可能とする。

- 管理者が開催日、対象レース、出走馬、担当者を登録できる。

- 専門家がスマートフォンで全頭を評価できる。

- 事前評価とパドック評価を並べて最終判断できる。

- 本命、対抗、穴、危険馬、見送り、信頼度を公開できる。

- 管理者がWIN5商品と対象5レースを設定し、担当者が中心馬、相手候補、注目馬、危険馬、理由、展開見解を入力できる。

- WIN5の対象5レースの馬評価を前日に紙面形式で公開できる。

- 無料、1日利用、創設、通常月額の閲覧権限を正しく分けられる。

- 公開から30秒以内に会員画面へ反映できる。

- LINE送信を公開後60秒以内に開始できる。

- 公開済み予想を直接上書き・削除できない。

- 訂正履歴、公開者、公開時刻、変更理由が残る。

- WIN5の最初の対象レース締切後は管理者も初版・訂正版を作成できず、旧版が残る。

- 無料会員APIへWIN5の中心馬、相手候補、注目馬、危険馬、馬番、理由、詳細見解を返さない。

- レース結果から全予想の本命馬1着・連対・複勝と候補内選出を再計算できる。

- 外れた予想も削除されず公開成績へ反映される。

- WIN5とパドック直前予想の馬評価成績を分離して再計算できる。

- 結果確定後だけSNS共有文、結果URL、共有画像を生成できる。

- 月額契約を利用者自身で解約予約できる。

- 自動投票、購入代行、賭け金預かりの機能が存在しない。

- 管理者・専門家の二段階認証、権限制御、監査ログが動作する。

- typecheck / lint / test / build がCIで成功する。
