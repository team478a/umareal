# Phase 5A 無料会員登録

LPからの流入後に無料登録を完了できる最小経路を実装した。CMSは含めない。Webアプリを会員・同意・権限の正本とし、LINEを主な登録・ログイン・通知経路、確認済みメールを復旧と有料化前の予備経路として扱う。

## 実装範囲

- LINE LoginのREGISTERフロー。state、nonce、PKCE、署名検証後に15分有効・使い切りの登録grantを発行する。
- 表示名、20歳以上確認、版付き利用規約・プライバシー同意からLINE無料会員を作成する。
- メール登録は会員作成後に30分有効の確認URLを送り、確認完了までログインを拒否する。再送応答は登録有無を伏せる。
- LINE登録者はマイページから予備メールとパスワードを追加できる。確認完了前の値は会員本体へ反映しない。
- 予備認証がないLINE会員のLINE解除と有料プラン申込をAPIで拒否する。
- ローカルmail transportとResend transport。ローカルはGit管理外ファイルへ保存し、本番はResend以外を拒否する。
- 管理会員一覧に登録経路とメール確認状態を表示する。

## データ保護

メール確認tokenとLINE登録grantはハッシュだけを照合に使う。LINE subjectは登録完了までAES-256-GCM暗号文とハッシュで保持し、使用時に暗号文を置換する。LINE subject、token、メール資格情報を監査詳細やログへ保存しない。同意履歴は登録経路と文書版を記録する。

## 境界

ローカルでは実LINE OAuthと実メール送信を行わない。正式な利用規約・プライバシーポリシー、実Supabase、LINEのライブ資格情報、配信ドメイン認証、本番デプロイは別作業とする。LPとCMSは対象外。
