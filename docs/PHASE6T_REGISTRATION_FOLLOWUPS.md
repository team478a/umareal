# Phase 6T 本人確認フォロー

## 目的

無料登録からメール確認までの離脱を運営が把握し、会員から未着連絡があった場合に安全な再送手順を使えるようにする。

## 実装

- `/admin/registration-followups` に確認待ち人数、登録30分以内、30分以上の件数と会員一覧を表示する。
- 一覧APIはADMIN+AAL2だけにメール、表示名、登録時刻、直近送信時刻を返す。無効会員、確認済み会員、LINE登録は対象外とする。
- ローカル認証では理由を必須にして確認メールを再発行する。会員単位のDBロック、確認状態の再検証、5分の再送間隔、監査記録で二重操作を抑止する。
- Supabase認証では管理者代理再送を拒否する。会員へ`/verify-email`を案内し、本人ブラウザーでPKCE verifierを発行して再送する。
- 管理画面はカード形式で、デスクトップとスマートフォンの両方に対応する。

## 対象外

- 自動リマインド、一括再送、SMS、CRM連携
- ResendおよびSupabaseのライブ資格情報を使った実送信
- 30分と5分を管理設定にする機能

## 検証

型検査、lint、単体テスト、API/DB結合テスト、デスクトップ・モバイルE2E、ビルドを実行する。結合テストではAAL2、期限経過一覧、理由必須、メール生成、監査追記、5分以内の再送拒否、確認完了後の一覧除外を確認する。
