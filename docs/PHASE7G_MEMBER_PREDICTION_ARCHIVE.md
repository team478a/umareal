# Phase 7G 会員向け過去予想検索

## 目的

配信済みの通常レース予想と確定結果を、会員が開催日を一日ずつ移動せずに探し直せるようにする。公開済み履歴の保存方式、課金区分、Entitlementは変更しない。

## 実装範囲

- `/races`で従来の単日検索と、最大93日の期間検索を切り替える。
- レース名または出走馬名、競馬場、予想の公開状態、結果の確定状態で絞り込む。
- 期間検索は新しい開催日から表示し、単日検索は従来どおり発走順で表示する。
- 一覧に最新予想版、訂正版、公開範囲、最新結果版、レース中止を表示する。
- PCとスマートフォンで同じ検索条件とページネーションを利用する。

## 情報公開境界

一覧APIは予想本文、印、評価、信頼度、結果の着順・人気・オッズを返さない。有料予想本文の取得は既存のレース詳細APIでサーバー側Entitlementを再判定する。検索語に馬名を指定しても、返るのは一致したレースの公開メタデータだけである。

## 技術境界

- 既存`Race`、`RaceEntry`、`PredictionVersion`、`RaceResultVersion`を参照し、DB migrationは追加しない。
- 単日`date`と期間`dateFrom`/`dateTo`の同時指定、不完全な期間、93日を超える期間を拒否する。
- 外部データ取得、外部AI、通知、本番deploy、本番migrationは行わない。
