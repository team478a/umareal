# Phase 7F 開催日運用の優先対応一覧

管理ダッシュボードの開催日運用ボードへ、その時点で先に確認すべき項目を優先順で表示する。

## 実装範囲

- 通知失敗と、発走30分以内または期限超過の作業を「緊急対応」とする。
- レースごとに、準備、告知、パドック、最終予想、結果のうち最初に止まっている工程を1件表示する。
- 通知失敗は工程上の停止項目とは別に表示し、配送確認へ直接移動できるようにする。
- 緊急件数と確認件数を集計し、緊急を先、同じ重要度では発走順に並べる。
- 各項目からレース管理、配信予約、評価・公開、通知、結果の既存画面へ移動する。
- 既存の30秒更新、日付切替、ADMIN/OPERATOR認可を維持する。

## 境界

- 状態を読み取って案内するだけで、公開、通知再送、結果確定を自動実行しない。
- DB schema、公開期限、担当制御、AAL2要件、既存の警告・リハーサル判定を変更しない。
- 会員連絡先、LINE識別子、評価本文、配送先、秘密値を応答へ追加しない。
