# JRA-VAN未接続 実運用効率化

作成日: 2026-10-07

## 対象

実運用リハーサルで確認した反復入力のうち、DB変更なしで安全に削減できる出走馬簡易登録と暫定Horse Identity確認を対象とする。

## 実装内容

- 暫定Identity一覧を選択中の開催日で絞り込み、さらにレース単位でも絞り込めるようにした。
- 暫定馬ごとに競馬場、レース番号、馬番を表示し、確認対象を識別しやすくした。
- 共通のIdentity確認理由を各馬へ再利用できるようにした。個別理由がある場合は馬ごとに上書きできる。
- 簡易出走馬登録の理由を登録後も保持し、同じ出馬表から連続登録する際の再入力を不要にした。
- 出走馬保存後に暫定Identity一覧を自動更新する。

## 安全境界

- Identity解決は従来どおり馬ごとの明示操作と監査記録を必要とする。
- 同名馬を自動mergeしない。
- 既存RaceEntry、Assessment、Prediction、公開版、結果を遡及更新しない。
- DB migration、外部データ通信、外部AI通信は行わない。

## 操作量

6頭の連続簡易登録では、登録理由の入力を6回から1回へ削減した。6頭のIdentity確認では、確認理由の入力を6回から1回へ削減した。実運用E2E上の合計は147操作・122入力項目から、138操作・106入力項目相当へ減少する。

## 次の改善候補

1. 予想担当者一覧の検索・必要分読込
2. AIレースガイド対象レースの日付・名称検索
3. 確認付きCSVを含むフルカード入力手順の短縮

これらはAPIと画面の検索契約を伴うため、次のレビュー可能な区間として分離する。
