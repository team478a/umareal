# Phase 7F CMSレース関連付け

## 目的

レース前後に公開する記事、動画、音声を対象レースとつなぎ、会員がレース詳細から関連コンテンツを見つけられるようにする。

## 実装範囲

- 管理者と編集担当は、CMSで開催日を選び、登録済みレースを最大10件まで指定できる。
- 下書き保存と公開確定の両方で対象レースの存在をサーバーとPostgreSQLが確認する。
- 関連レースは公開版に凍結し、旧版を更新・削除しない。
- 公開中の最新版だけをレース詳細に表示する。コンテンツ詳細からは関連レースへ戻れる。
- 有料コンテンツの本文とメディアURLは、関連レースAPIでは返さない。

## 対象外

関連馬、自動関連付け、固定ページ、メディアアップロード、本番配備は含めない。
