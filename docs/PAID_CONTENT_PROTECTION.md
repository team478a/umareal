# 有料コンテンツの転載は禁止転載対策

## 目的

有料会員向けの予想を、正規の権限を持つ会員だけに配信し、画面撮影による無断転載を抑止する。

## 現在の対策

- 通常レース紙面、WIN5紙面、最終予想のうち、公開範囲が有料の本文だけに透かしを表示する。
- 透かしには氏名やメールアドレスを使わず、会員IDから作った識別コードとJSTの閲覧時刻（分単位）を表示する。
- 透かしは本文の上に重ね、長いページとスマートフォン表示でも複数箇所に入る。
- ブラウザーの印刷では有料本文を非表示にする。
- 閲覧可否は従来どおりサーバー側の権限判定を正とする。透かしは権限判定の代替ではない。

## 限界

WebサイトからOSのスクリーンショット機能、別端末での撮影、開発者ツールによる保存を完全に停止することはできない。そのため、「スクリーンショットできない」とは案内せず、「個別透かしによって流出を抑止し、流出元の調査材料にする」と案内する。

右クリック、コピー、文字選択の一律禁止は、容易に回避できる一方でアクセシビリティと通常利用を損なうため採用しない。

## 動画・音声配信を有料化するとき

恒久的な外部動画URLを本文へ貼らない。配信事業者を決定した後、次を組み合わせる。

1. 会員権限を確認した後だけ発行する短時間の署名付き再生URL
2. 許可ドメインからの埋め込み制限
3. 同時再生数と端末数の制限
4. HLS/DASH暗号化またはDRM
5. 再生画面上の動的な会員識別透かし

DRMを導入しても別端末による撮影は防げないため、動画でも個別透かしは維持する。

## 確認項目

- 無料公開の本文には透かしが出ない。
- 権限のない会員には有料本文が返らない。
- 有料本文には会員識別コードと現在のJST時刻が出る。
- 氏名とメールアドレスは透かしへ含めない。
- スマートフォン幅でも透かしが本文全体に複数表示される。
- 印刷プレビューに有料本文が出ない。
