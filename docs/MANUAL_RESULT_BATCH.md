# 結果の確認付き一括入力

作成日: 2026-10-07

## 目的

JRA-VAN未接続の手動運用で、各馬の着順・人気・確定単勝をフォームへ個別入力する反復を減らす。正式CSVファイルを作らなくても、公式結果を見ながら1レースの全出走馬を貼り付け、既存の差分確認と下書き境界を通して保存できるようにする。

## 管理画面の操作

1. `/admin/results`で発走済みの対象レースを選ぶ。
2. 「かんたん結果一括入力」へ1行1頭で入力する。
   - 完走: `馬番,着順,人気,確定単勝`
   - 取消: `馬番,取消`
   - 除外: `馬番,除外`
   - 競走中止: `馬番,競走中止`
3. 「入力内容を確認」で全頭の差分を表示する。
4. 公式結果と照合し、確認理由を入力して下書きへ反映する。
5. 下の着順・状態一覧を再確認し、「結果を確定」を実行する。

レース全体の中止、詳細な個別訂正、正式CSV、複数レースCSVは既存画面を維持する。

## 安全境界

- 共通Domain parserが最大18頭、馬番、着順、人気、単勝、例外状態、重複を決定的に検証する。
- 例外状態に着順・人気・単勝が付いている入力を拒否する。
- 画面内で既存の内部標準CSVへ変換し、既存の`POST /admin/results/races/:raceId/import/preview`を通す。
- サーバー側で対象レースの全RaceEntryが1回ずつ存在することを再検証する。
- プレビューは15分有効で、出走馬、発走時刻、結果下書きが変わった場合は反映を拒否する。
- 下書き反映と結果確定を分離し、自動確定・自動通知を行わない。
- 確定結果は上書きせず、新しい結果版として追記する。
- 払戻、券種、買い目、購入金額は入力・生成しない。

## 再利用した既存機能

- ADMIN/OPERATORとAAL2のサーバー認可
- 結果CSVの全頭照合
- 差分プレビュー
- ImportBatch、期限、競合検知
- `RACE_RESULT_CSV_IMPORT_CONFIRMED`監査
- 結果下書き、確定結果版、成績反映、通知
- CSV取込の緊急停止設定

新しいAPI、DB table、migrationは追加しない。

## 操作量

6頭のリハーサルでは、結果工程を21操作・19入力から6操作・2入力へ削減した。12レース各18頭でも、648項目の個別フォーム入力ではなく、12回の貼り付け・差分確認・下書き反映へ短縮できる。公式情報との照合と結果確定は引き続き人が行う。

## 検証

- Domain unit: 通常完走、タブ区切り、取消、除外、競走中止、重複、不完全行、例外状態への数値混入、18頭上限、内部標準CSV再解析。
- E2E desktop/mobile: 6頭貼り付け、差分確認、下書き反映、全頭照合、結果確定、成績反映、公開済み予想の不変性、監査確認。
- 外部競馬データ、外部AI、外部HTTP通信は使用しない。
