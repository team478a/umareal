# Phase 5D 会員向けお知らせ履歴

LINEの受信成否に依存せず、対象レース告知と予想公開をWebアプリ内で確認できるスマートフォン向け履歴を実装した。

## 実装範囲

- ログイン会員向けの`/notifications`画面とナビゲーションを追加する。
- 対象レース告知、無料予想公開、訂正版を新しい順に表示する。
- 有料予想イベントは現在有効な月額または対象日の1日利用権限がある場合だけ返す。
- 履歴APIにはレース基本情報、公開種別、版、公開時刻だけを返し、予想本文・印・買い目を含めない。
- 会員別に既読時刻を保存し、すべて／未読を切り替える。
- 詳細ボタンで冪等に既読化してレース詳細へ移動する。

## 境界

LINEの開封計測ではなく、Web履歴の既読状態である。プッシュ通知、メール通知、CMS、外部決済、本番接続は追加しない。期限切れ後の有料履歴表示は過去予想の閲覧方針が未確定なため、現在の権限判定と同じく有効期間内に限定する。
