# Phase 5F 会員ホーム行動案内

無料登録後の会員が、告知確認、LINE設定、有料化、レース閲覧のどこから進むか迷わないよう、ログイン後ホームへ状態と次の操作を表示した。

## 実装範囲

- 未読お知らせ件数、LINE受信準備、無料・有料会員状態をホームに表示する。
- 未読があればお知らせ確認、次にLINE設定、無料会員なら料金確認、有料会員ならレース確認を案内する。
- 上部通知ベルとサイドメニューに未読件数を表示する。
- 通知詳細へ移動して既読になった後、画面遷移時に未読件数を再取得する。
- Webお知らせを会員登録後に発生したイベントへ限定し、新規会員に過去イベントを未読表示しない。
- デスクトップとスマートフォンで同じ状態と導線を利用できる。

## 境界

行動案内の優先順は開発初期値であり、アクセス解析やA/Bテストは行わない。CMS、広告計測、外部決済、LINE・メールのライブ疎通、本番デプロイは含めない。
