# Phase 5B 対象レース告知

無料登録後の「予想レース告知→情報配信」へ進むため、CMSを導入せず、登録済みレースから定型告知を公開する機能を実装した。

## 実装範囲

- ADMIN+AAL2またはOPERATORが、スマートフォン向けのレース管理画面から理由付きで対象レースを告知する。
- 告知は版番号を持つ追記専用データとして保存し、DBトリガーで更新・削除・TRUNCATEを拒否する。
- 同じリクエストキーの再送は同じ結果を返し、再告知は次の版として追加する。
- 告知と同じトランザクションで`RACE_ANNOUNCED`通知eventを作成する。
- LINE通知は無料会員を対象にし、通知設定とLINE連携状態を展開時と送信直前に確認する。
- 通知文には開催日、競馬場、レース番号、レース名、会員ページURLだけを含める。
- ホームへレースごとの最新告知を表示し、レース詳細へ移動できるようにする。
- 通知管理画面で対象レース告知と予想公開通知を同じ配送基盤から確認・再送できる。

## 境界

自由文記事や画像を作るCMSではない。告知文は定型で、運用理由は監査用として会員へ公開しない。予約告知、LINEのライブ送信、開封計測、本番デプロイは別区間とする。
