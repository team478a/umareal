# Phase 5K 障害対応チェック

公開・取込・LINE通知の停止や配送異常を一画面で確認し、初動から復旧確認までを順番に進められるようにした。

## 実装範囲

- 予想公開、CSV取込、LINE通知の停止とLINE資格情報不足を検知する。
- 失敗配送、60秒を超えた初回処理待ち、5分を超えた送信中を検知する。
- 24時間以内の未照合LINE Webhookを検知する。
- 状態を正常、要確認、障害対応中に分類し、30秒ごとまたは手動で更新する。
- 検知、Web公開確認、影響抑制、原因解消、復旧確認の手順を表示する。
- 運用ボード、通知履歴、緊急停止設定、監査ログへ移動できる。
- 現在の障害状態に応じた会員向け案内文案をコピーできる。
- ADMINとOPERATORの権限差を維持し、秘密情報をAPIへ返さない。

## 境界

障害対応画面は状態確認と手順案内だけを行う。緊急停止、再送、公開、外部連絡は既存の理由入力・監査付き画面または別運用で実施する。案内文を自動送信しない。外部監視サービス、障害連絡網、バックアップ復元、本番ロールバックは含めない。
