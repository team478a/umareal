# Phase 2 第2区間：事前評価とパドック入力

2026年9月12日。担当専門家がスマートフォンで事前評価と全頭のパドック評価を入力する機能を追加しました。本番サービスの完成や予想公開の実装ではありません。

## 実装した動作

- 担当レース一覧から評価画面を開き、馬番順に前後移動または直接選択。
- 事前点数0〜100、順位1〜18、印、短評を部分保存。
- 馬体の張り、歩様・踏み込み、毛艶、気合・集中力、発汗、落ち着きを1〜5または判断不能で入力。現在の1頭だけへ6項目を同じ値で明示設定する短縮操作と、各項目の個別調整を用意。総合変化と短評、定型文候補は別に入力する。
- 利用者＋レース単位で端末へ一時保存し、自動同期。保存済み/送信中/未送信/競合、全頭進捗と未入力馬を固定表示。
- 別端末とのrevision競合を検出し、端末値とサーバー値を比較して明示的に採用。出走馬・担当・レース変更も再確認を要求。
- 現在値とは別に、各保存の内容・出走馬スナップショット・操作者・理由を追記。履歴の更新・削除・TRUNCATEをDBトリガーで拒否。
- 担当EXPERT+AAL2またはADMIN+AAL2のみをAPIで認可。クライアントから送られたロールは受理しない。

## セキュリティとデータ保護

権限、担当、MFA、出走馬ID、レースrevision、評価revisionをサーバーで再確認します。正常保存では現在値・追記履歴・監査・冪等キーを同じDBトランザクションで確定します。評価済み馬を別の馬IDへ入れ替える管理API/CSV操作も拒否します。

localStorageには未送信の評価内容が平文で残るため、共有端末の利用を避ける案内を表示します。利用者・レース別の端末下書きは最終更新から最大24時間保持し、送信完了、画面の明示消去、正常ログアウト、LINE会員切替、退会完了、期限到達時に消去します。正常な認証終了時はレース・出走馬・結果入力のsession下書きも合わせて消去します。認証終了APIが失敗した場合は復旧用の下書きを残します。旧形式の期限なし下書きは初回読取時に同じ期限付き形式へ移行します。秘密情報、認証トークン、決済情報は保存しません。

## 追補: 発汗と落ち着きの分離（2026-10-07）

- 新規評価は`発汗`（`sweating`）と`落ち着き`（`calmness`）を別々に0〜5で保存する。まとめ入力は現在の1頭の6項目だけに反映する。
- 旧版の`発汗・落ち着き`（`calm`）は版付きJSONと公開済みsnapshotのまま保持し、2項目へ推測分割しない。旧値だけを持つ評価も従来どおり完了として読める。
- APIから旧合成値を新規作成・変更することは拒否する。旧評価の別項目を修正する場合は合成値を保持でき、発汗または落ち着きを入力し始めた場合は両方を確認するまで未完了とする。
- JSON contractの後方互換追加であり、DB schema、既存履歴、公開版、本番環境は変更しない。
