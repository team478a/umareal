# 通常レース結果CSV取込

2026年9月15日。発走後の通常レース結果をCSVで検証し、現在の結果下書きとの差分を確認してから反映できる機能を追加した。

## 実装範囲

- UTF-8 CSVの見出し、最大サイズ、列数、値、状態と着順の整合性、馬番重複を共通ドメインで検証。
- 対象レースの全登録馬との馬番照合。未登録馬と不足馬を拒否。
- 現在の結果下書きとの差分プレビュー、15分の有効期限、同一担当者だけの確定、再送時の冪等応答。
- プレビュー後のレース、出走馬、発走時刻、レース状態、結果下書き変更を検出して反映を拒否。
- 管理画面のファイル選択、直接入力、サンプルCSV、差分表示、理由付き下書き反映。
- CSV緊急停止のプレビュー時・確定時確認と監査ログ。
- 開催日・競馬場・レース番号を含む複数レースCSV、レース別差分、全件成功または全件取消の一括下書き反映。
- 一覧での「CSV取込済み・確認待ち」表示と、レース別確認への導線。
- 内部標準CSVと`JRA_VAN_BRIDGE_V1`を分離する結果データ提供元インターフェース。
- JRA-VAN競馬場コード・異常区分コードの共通形式への変換、取込元・形式版・SHA-256ファイル指紋のプレビューと監査。
- 同じ取込元・同じファイル指紋のプレビュー／確定／DB制約による重複防止。
- 同じ対象レース集合の変更ファイルを公式訂正として前回batchへ関連付け、最近30件を管理画面へ表示。

CSV確定後も結果は未確定である。担当者が画面で内容を照合し、既存の「結果を確定」を実行した時点で追記専用の結果版、馬評価、会員通知が作成される。

## 対象外

JRA-VAN契約・利用許諾の確定、JV-Linkを使うWindowsブリッジ実行ファイル、ライブデータ疎通、CSVからの自動結果確定、WIN5へのCSV直接取込、払戻・券種・買い目・購入金額の取込、本番データ取込は行わない。
