# Phase 6O 新規会員登録の停止・再開

## 目的

募集枠の確認や登録障害が起きた際に、サービス全体を止めず、新規会員の作成だけを管理画面から安全に停止・再開する。

## 実装範囲

- `/admin/settings` に新規会員登録スイッチと、停止中の会員向け案内を追加した。
- 管理者+AAL2、変更理由、設定revisionを必須とし、変更前後を監査ログへ保存する。
- メール登録、LINE OAuthの新規登録開始、LINE登録確定をAPIで拒否する。
- 公開設定APIで受付状態を返し、登録導線を非表示にして `/register` に停止案内を表示する。
- 既存会員のログイン、メール確認、パスワード再設定は利用可能なまま維持する。
- PostgreSQL制約により、停止状態で会員向け案内が空の設定を拒否する。
- 登録作成時は設定行を共有ロックし、停止操作との順序をデータベースで確定する。

## 運用

停止理由として入力する監査用の文面は管理者だけが確認する。会員に表示してよい日時や再開見込みは、別の「登録停止中の会員向け案内」へ入力する。再開後は公開設定APIから停止案内を返さない。
