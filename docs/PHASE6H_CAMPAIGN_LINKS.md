# Phase 6H キャンペーンURL発行・集計CSV

管理者は `/admin/acquisition` でLP・広告用の無料登録URLを発行できる。

- 管理用名称、キャンペーンコード、流入元、媒体、任意のコンテンツ識別・紹介コード、登録先パス、発行理由を入力する。
- キャンペーンコードは一意で、小文字へ正規化する。登録先はアプリ内のパスだけを許可する。
- 発行済みURLは読み取り欄から選択でき、対応ブラウザーではコピーボタンを利用できる。
- 7日、30日、90日、365日の流入別無料登録数、有料化数、有料化率を表示する。
- CSVは同じ集計を出力し、個人情報を含めず、表計算ソフト向けの数式注入を防止する。
- 作成操作は監査ログへ追記する。初期運用では編集・削除せず、訂正時は新しいコードを発行する。
