# 記事・動画・音声CMS

## 目的と画面

管理者と編集担当が `/admin/content` で会員向けの記事・動画・音声を作成する。公開中のコンテンツは `/content` に一覧表示し、詳細は `/content/<contentId>` で閲覧する。

## 権限

- `ADMIN` はAAL2完了後に作成、編集、公開予約、即時公開、公開終了、再編集を行える。
- `EDITOR` は通常ログインでCMSだけを操作できる。会員、課金、レース、通知、秘密設定にはアクセスできない。
- `OPERATOR` と `EXPERT` はCMSを操作できない。
- 編集担当を利用停止または別ロールへ変更するとき、未実行の公開予約がある場合は先に予約を取り消す。

## 公開手順

1. 種類、タイトル、概要、本文、カテゴリ、タグ、公開範囲を入力する。必要な場合は開催日から関連レースを最大10件、馬名検索から関連馬を最大10頭選択する。動画と音声はHTTPSの配信URLが必須で、ファイル自体はアプリへ保存しない。
2. 「下書きを保存」で内容を保存する。公開済みコンテンツを編集しても、再公開するまでは直前の公開版が会員へ表示される。
3. 即時公開する場合は理由を入力して「今すぐ公開」を選ぶ。予約する場合は未来の日時と理由を入力して「公開予約」を選ぶ。
4. 公開後の修正は新しい版として追加する。公開済みの種類は変更できないため、記事から動画などへ変える場合は新規作成する。
5. 掲載を止める場合は「公開終了」を選ぶ。物理削除はせず、公開版と監査履歴を保持する。「再編集」で下書きへ戻しても、再度公開するまでは非公開のままとする。

公開した関連レースと関連馬はその公開版に固定される。関連先を変更するときも新しい版として公開し、旧版を書き換えない。公開中のコンテンツはレース詳細に表示され、コンテンツ詳細からも関連レースへ戻れる。関連馬は既存のHorseだけを選択し、名前一致による自動統合や記事本文からの自動推定は行わない。Horse Cardは未実装のため、会員画面では馬名を表示するだけとする。

## 公開通知

- 初版公開では`CONTENT_PUBLISHED`、第2版以降では`CONTENT_UPDATED`を、公開版と同じDBトランザクションで1件だけ登録する。即時公開と予約公開のどちらにも適用する。
- ログイン済み会員のお知らせ履歴には、コンテンツ種別、タイトル、カテゴリ、公開時刻、版、詳細画面へのリンクだけを表示する。
- LINE・メールは、会員が「記事・動画・音声の更新」を有効にしている場合だけ送る。メールは確認済みかつメール通知有効、LINEは有効な連携が必要になる。
- `有料会員限定`は、通知対象の確定時と送信直前の両方で、現在の権限とプラン別コンテンツ提供設定を確認する。権限を失った会員には送らない。
- 通知には本文、概要、動画・音声の配信URL、会員限定情報を含めず、アプリ内の`/content/<contentId>`へ案内する。

## 公開範囲と課金

- `一般公開`: 未ログインでも本文を閲覧できる。
- `無料会員以上`: ログイン済み会員とスタッフが閲覧できる。
- `有料会員限定`: 有効な閲覧権限と管理画面のコンテンツ提供設定を両方満たす会員だけが本文を閲覧できる。

初期設定では月額会員と手動付与に記事・動画・音声を提供し、1日利用には提供しない。`/admin/settings` のプラン別コンテンツ提供設定で変更できる。権限がない閲覧者へはタイトル、概要、カテゴリ、公開日時だけを返し、本文と配信URLをAPIレスポンスへ含めない。有料本文には既存の個別透かしを表示する。

## 安全境界

- 公開版はPostgreSQLでも更新・削除を拒否する追記専用データとする。
- 作成、更新、予約、予約取消、公開、公開終了、再編集を理由付きで監査する。
- 同時編集はrevision不一致で停止し、再読み込みを求める。
- 予約公開時は、予約した担当者が有効な`ADMIN`または`EDITOR`であることと、予約後に下書きが変更されていないことを再確認する。
- 固定ページ編集、動画・音声ファイルのアップロード、配信事業者の署名付きURL発行は行わない。
