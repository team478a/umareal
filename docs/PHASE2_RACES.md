# Phase 2 第1区間：レース管理

2026年9月12日。Phase 0 / 1の基盤に、開催日・レース・出走馬・担当専門家の管理とCSV取込を追加しました。

## 実装した動作

- `/admin/races` で開催日・レースの登録、発走時刻等の編集、専門家割当、出走馬の追加・編集・取消/除外/中止を記録。
- レースCSVと出走馬CSVの入力検証、行・項目別エラー、変更前後プレビュー、理由付き確定、サンプルダウンロード。
- DBの一意制約、手動更新のrevision確認、取込プレビューの15分期限と競合確認、確定の冪等性、トランザクションによる全件適用。
- サーバー側の管理者AAL2/運営担当権限と監査ログ。担当専門家の一覧へ登録レースを反映。
- 既存レースを保持する追加マイグレーション。CSVにないレース・出走馬は保持。データ提供元の切替境界としてRaceDataProviderを追加。

## 確認方法

ローカル起動後、管理者でログインして二段階認証を完了し、レース管理を開きます。詳細は[CSV取込手順](CSV_IMPORT.md)。変更理由は操作履歴に残ります。専用テストは架空の会員・馬・将来日のレースを追加し、既存データを削除しません。

## 制限と次区間

次は事前評価とスマートフォンのパドック入力です。その後に最終予想・公開プレビュー・追記専用公開版・訂正を実装します。公開版と凍結した印・買い目のDB保護、発走締切の強制、延期時の扱いはその区間の必須事項です。今回は監査ログの保護を維持していますが、予想公開自体は未実装です。

課金/LINE Webhook、本番Supabase接続、結果・払戻・集計、CMS、本番デプロイは未実施。管理APIの排他は小規模な運用を想定した共通DBロックです。外部データ更新やワーカーを導入する際は排他契約と負荷を検証します。正式なデータ提供元・利用許諾・事業判断はDECISIONS.mdで保留しています。
