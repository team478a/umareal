# 管理画面の検索・読込効率化

作成日: 2026-10-07

## 目的

テスト担当者やレースが増えた環境でも、管理画面の初期表示で全件を読み込まず、運営担当者が必要な対象を短時間で選べるようにする。

## 実装内容

- レース管理の予想担当者を表示名で検索し、最大50件だけ取得する。
- WIN5管理でも同じ担当者検索APIを使用し、最大50件だけ取得する。
- 編集中のレース・WIN5に割当済みの担当者は、別の検索結果を表示しても選択肢に保持する。
- AIレースガイドの対象レースを開催日、競馬場、レース名で検索する。
- AIレースガイド一覧を50件単位でページ移動し、総件数を表示する。

## API契約

- `GET /api/v1/admin/race-experts?page=&limit=&search=`
- `GET /api/v1/admin/ai-guide/races?page=&limit=&date=&venue=&keyword=`

両APIとも既存の管理認証と権限を維持し、件数上限をサーバー側で検証する。

## 安全境界

- DB migrationは行わない。
- 担当割当、公開版、Entitlement、監査、AI生成入力は変更しない。
- 担当者のメールや認証情報を検索結果へ返さない。
- AIガイド検索へAssessment、Prediction、三国谷コメント、会員情報を使用しない。
- 外部通信、本番deploy、本番migrationは行わない。

## 確認項目

- 担当者名の部分一致検索で対象者を選択できる。
- 検索前に割り当てた担当者が編集時に失われない。
- 日付・競馬場・名称を組み合わせて対象レースを絞り込める。
- 検索後もBasic Guideの生成、確認、公開が従来どおり動作する。
- PC・スマートフォンで横スクロールを発生させない。
