# Phase 2 第3区間 実装報告

> この文書は旧方式の実装履歴です。現行仕様は [SPEC.md](SPEC.md) と [HORSE_EVALUATION_MIGRATION.md](HORSE_EVALUATION_MIGRATION.md) を参照してください。

## 実装した動作

- 担当専門家と管理者向けの最終予想下書き、見送り、印、参考買い目入力
- 公開前プレビューと、確認後の変更を拒否する再検証
- 発走締切をAPIとPostgreSQLの両方で強制
- 初版公開と、旧版を保持した訂正版の追加
- 公開版、凍結印、買い目、監査履歴のDBレベルでの更新・削除防止
- 公開版と同じトランザクションで通知イベントをQUEUEDとして作成
- FREE版の一般公開と、有限期間権限に基づくPAID版本文のサーバー側秘匿
- FREE版とPAID版が混在する訂正履歴の版単位認可
- 会員画面の版履歴表示と、専門家画面のスマートフォン向け入力・確認フロー

## 実装上の境界

訂正承認は開発既定値 `ADMIN_ONLY`、延期後の締切再開は開発既定値 `CLOSED` とした。どちらも本番方針ではなく、決定事項と保留事項は `docs/DECISIONS.md` に記録している。

通知イベントの外部送信、再試行、宛先判定、結果・成績集計、課金接続、本番デプロイは含まない。買い目は参考情報の保存と表示だけで、購入、自動生成、資金の預かりは行わない。

## 検証結果

- Prisma生成、全共有パッケージとアプリのプロダクションビルド: 成功
- TypeScript型検査、ESLint: 成功
- ドメイン単体試験15件: 成功。公開必須項目、見送り、券種別組合せ、100円単位、重複制約を含む
- API/DB統合試験19件: 成功。認可、MFA、担当、冪等性、競合、プレビュー、公開原子性、訂正履歴、版単位の有料本文秘匿、発走締切、DB不変条件を含む
- Chromium E2E 14件: desktop/mobileとも成功。FREE初版とPAID訂正版の版単位閲覧、旧版保持、18頭の全パドック項目入力から見送り公開までを含む
- Prisma migration status: 6件適用済み、schemaは最新

18頭の自動操作はdesktop 7.4秒、mobile 7.2秒だった。これは操作経路と性能退行を検出する試験であり、実機で人が行う3分運用試験は本番前に別途必要。
